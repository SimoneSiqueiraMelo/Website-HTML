Se você já abriu o “Inspecionar elemento” do navegador e ficou se perguntando o que significam aquelas tags, você está no lugar certo.
O HTML é o primeiro passo no desenvolvimento web e funciona como o esqueleto de qualquer site.

O que é HTML?

HTML significa HyperText Markup Language (Linguagem de Marcação de Hipertexto).
Apesar de muita gente achar que é uma linguagem de programação, o HTML na verdade é uma linguagem de marcação, usada para estruturar o conteúdo de uma página web.

Com o HTML, o navegador entende o que é:

  • título
  • parágrafo
  • imagem
  • link
  • lista
  • formulário

Sem HTML, não existe site 😉

Estrutura Básica do HTML

Todo documento HTML segue uma estrutura padrão. Ela é essencial para que o navegador interprete corretamente a página.

Exemplo de estrutura básica:

                    
                        <!>DOCTYPE html>
                           <html lang="pt-BR">
                               <head>
                                   <meta charset="UTF-8">
                                   <title>Meu primeiro site</title>
                               </head>
                               <body>
                                   <h1>Hello, HTML!</h1>
                                   <p>Esse é o conteúdo da página.</p>
                               </body>
                           </html>

  • DOCTYPE html

    Define que o documento está usando HTML5.

  • html

    É a raiz do documento, envolve toda a página.

  • lang="pt-BR"

    Define o idioma da página.

  • head

    Contém informações internas da página (não visíveis).

  • meta charset="UTF-8"

    Permite exibir acentos e caracteres especiais corretamente.

  • title

    Define o título que aparece na aba do navegador.

  • body

    Contém todo o conteúdo visível do site.

  • h1

    Título principal da página.

  • p

    Parágrafo de texto.

PRINCIPAIS TAGS HTML

As tags HTML são responsáveis por estruturar e organizar o conteúdo da página. Cada uma possui uma função específica dentro do documento.

                
                    <h1>Título principal</h1>
                    <h2>Subtítulo</h2>
                    <p>Isso é um parágrafo.</p>

                    <strong>Texto em destaque</strong>
                    <em>Texto enfatizado</em>

  • h1 até h6

    Definem títulos e subtítulos, organizando a hierarquia do conteúdo.

  • p

    Cria parágrafos de texto.

  • strong

    Indica importância (geralmente exibido em negrito).

  • em

    Indica ênfase (geralmente exibido em itálico).

Essas tags ajudam o navegador e também mecanismos de busca a entenderem a estrutura do site.

LINKS E NAVEGAÇÃO

Links permitem conectar páginas e criar navegação entre conteúdos.

                
                    <a "https://www.dio.me" target="_blank">
                        Visitara DIO
                    </a>

                    <a href="#formularios" >
                        Ir para Formulários
                    </a>

  • a

    cria links.

  • href

    define o destino do link.

  • target="_blank"

    abre o link em nova aba.

Também é possível criar navegação interna usando âncoras com id.

IMAGENS NO HTML

Imagens deixam o site mais visual e informativo.

                
                    <src="imagem.jpg" alt="Descrição da imagem">

  • img

    insere uma imagem.

  • src

    caminho da imagem.

  • alt

    descrição alternativa (importante para acessibilidade).

A tag img não possui fechamento.
